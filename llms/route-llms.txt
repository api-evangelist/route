# Route

> Route is a post-purchase platform for e-commerce brands, offering package protection (shipping insurance), AI-driven returns, and real-time order tracking for merchants and their shoppers. Route is backed by Craft Ventures.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public surface (apis.yml + verified provider pages). It is not published by Route.
